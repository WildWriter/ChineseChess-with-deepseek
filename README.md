# 棋理学伴

面向中国象棋初学者的短局面训练应用：先自行走棋，再用规则证据、分级提示和讲解理解这一步。

当前是 **v0.1 本地可试玩版**。不需要注册，不依赖前端框架或 npm 第三方包。Node.js 22.9+ 即可运行。已按要求暂不发布博客、推送 GitHub 或公开部署。

## 启动

Windows 双击 `启动棋理学伴.cmd`，在浏览器打开 **http://127.0.0.1:8787/**。

新版源码包的内容、核验结果与分享边界见 `SUBMISSION.md`，伙伴操作清单见 `TESTING.md`。首次解压可运行 `node scripts/verify-package.js`，检查文件清单及 SHA-256。

也可以在此目录打开终端：

```powershell
node scripts/prepare-engine.js
node --env-file-if-exists=.env server.js
```

若权重缺失或损坏，可从固定上游提交补齐并校验：

```powershell
node scripts/prepare-engine.js --download
```

规则训练和教案不要求引擎就绪；点击“查看引擎参考分析”才启动 Pikafish。每次分析独立进程，单线程、64 MiB 哈希，搜索默认 600 ms，最多同时一个分析，避免持续占用 CPU。

按 Ctrl+C 停止终端服务。换端口时设置 `PORT`，见 `.env.example`。

## 已实现

- 20 个自编教学局面：8 道基础题 + 12 道残局，其中 4 道一步残局、8 道两至三步连续将杀。
- 图片残局研究：上传 PNG/JPEG/WebP，使用 deepseek-flash 识别，人工校正并确认；支持 FEN、红黑先行、1–3 步短将杀核验、Pikafish 参考、逐步演示、AI 解法讲解与分析导出。使用与验证边界见 `docs/IMAGE-ENDGAMES.md`。
- 基础／残局分类、车／马／炮／兵主题筛选、可展开题库和完成标记；下一题遵循当前筛选。
- 多步残局执红，黑方自动选择规则搜索内坚持最久的合法防守；记录双方着法，最后绝杀才计通关。不是只播放固定棋谱。
- SVG 棋盘，鼠标点击、键盘方向键与 Enter 操作、翻转棋盘、合法落点标记。
- 区分非法走法、合法但未达题目目标、完成目标；枚举接受全部正确将杀及应将，不只认教案示例。
- 3 级提示、示例落点、教案讲解及 E1–E4 规则证据。
- 错题自动记录、重练、完成标记、独立完成统计；查看提示或讲解后的作答不计为该轮独立完成。
- 浏览器事务存储学习记录，多标签页同步且不互相覆盖；自动迁移旧记录，兼容原 JSON 导出与导入，不收集联系方式或真实身份。
- Pikafish 原始局面参考分析，明确区分绝杀与困毙，不把评分换算成未经校准的胜率。
- 7 条规则小册与固定源码出处。
- 模型讲解与两条件对照评测接口、访问口令、跨站请求检查、资源限流、模型异常回退；引擎故障时明确降级为规则证据讲解。

## 模型功能与配置

点击页面右上角 **API 设置**，输入自己的 API Key，选择 `deepseek-flash`（默认）或 `deepseek-v4-pro`，点击“应用设置”后直接调用，无需重启。只支持页面手动输入，不再读取服务器环境中的模型密钥、模型名或接口地址。

“应用并测试连接”会向所选模型发送一次短请求，显示等待、成功、失败与原因。只应用设置不算测试成功。讲解和对照调用也会显示实际成功或失败，失败时不继续展示上一次的 AI 结果。

页面密钥只放在当前页面内存，经本机后端转发到 DeepSeek 官方接口，不写入浏览器存储或文件。清除按钮立即停用本页模型调用；刷新或重新打开页面后必须重新输入 Key，同一页面内连续调用无需重复填写。具体操作与验收见 `docs/API-PAGE-SETTINGS.md`。

本机已完成 DeepSeek API 基础联调，真实验证了车吃子和炮将杀两个代表局面，网页已能显示模型讲解。详见 `docs/API-VALIDATION.md`。其他电脑需要自行配置密钥；未配置时显示“教案模式”，教案不是大模型输出。

模型功能无需配置 `.env`。该文件只可选用于端口、监听地址、访问口令和引擎路径；即使旧文件留有 `LLM_API_KEY`、`LLM_MODEL` 或 `LLM_BASE_URL`，程序也不会使用它们。

分享项目压缩包时也要排除 `.env`；`.gitignore` 只影响 Git，不会自动过滤普通压缩包。

主动点击按钮才发起实际请求，可能产生费用。接口固定为 DeepSeek 官方 Chat Completions，不接受自定义接口地址；调用格式参考 [DeepSeek 官方接口说明](https://api-docs.deepseek.com/)。

短讲解使用 JSON 输出；DeepSeek 官方接口显式关闭默认思考模式，输出上限为 1024 tokens，避免思考占满额度而截断正文。模型仍可能输出不符合要求的内容，程序会保留校验与教案回退。只允许引用本题候选着法和实际引擎提供、再经规则验证的着法，不允许模型用引擎推荐替换本题作答字段。

定制流程：按题目标签检索本地规则条目 → 生成实际着法的规则证据 → 可选调用棋力引擎 → 组织教学提示 → 调用模型 → 检查 JSON 结构、候选 UCI 着法和证据编号 → 展示输出，校验失败则展示明确标识的教案。

本版校验不等于自然语言解释的完整事实核验。已完成的 API 连通与代表局面检查，不替代大样本模型评测、教学可理解性或真实用户学习效果检查。

## 测试

```powershell
node --test tests/*.test.js
node scripts/verify-curriculum.js
```

自动测试包含基础规则、20 题可解性、多解、多步残局、困毙与绝杀区别、接口错误处理、访问口令、跨站请求、模型结构校验、记录迁移与事务更新，以及可用时的真实引擎调用。模型测试使用 mock，不产生 API 费用。

初次基础浏览器验收记录见 `docs/ACCEPTANCE.md`，该阶段使用独立端口 8788。残局扩展见 `docs/ENDGAMES.md`，稳定性优化见 `docs/ROBUSTNESS.md`，图片残局检查见 `docs/IMAGE-ENDGAMES.md`。新功能使用独立测试端口，不覆盖 8787 的用户作答记录。当前回归测试为 **88 项通过，0 失败，0 跳过**。

## 题目设计边界

吃子题考查明确的基础规则目标，不宣称该着法在实战中全局最优。应将题只要求解除当前将军。将杀题必须同时满足“对方正在被将军”和“对方无合法走法”，困毙虽然在象棋中是胜局，但不计为完成将杀题。

多步残局限定红方每步将军、两至三个红方回合内绝杀；规则搜索穷举黑方全部合法应对，接受所有满足此目标的着法。它不是通用残局库、完整自由对弈或长将长捉裁定系统，也不把引擎胜负评分直接当作本题通关条件。

预置内容适合局部规则与短战术练习，不提供完整比赛裁判功能，例如长将长捉和循环局面裁定。图片与 FEN 可导入自定义残局；暂不包含 XQF/CBR 二进制棋谱、整盘文字棋谱导入、完整对局复盘、在线双人对战和语音。图片识别必须人工核对，不能凭模型输出直接判胜。
